# NR-004: Сервер и экран «Карта сети»

- **Статус:** draft
- **Риск:** medium
- **Зависимости:** NR-002, NR-003

## Описание

Сервер с API и веб-интерфейс «Карта сети» по макету `design/Main.dc.html`: граф топологии, значки по типам устройств, вкладка устройства по клику (обзор, диски, сеть, пользователь, правка), ручное добавление, именование, проверка и соединение элементов, пометка «не проверен», цвет связей по качеству.

## Меняемые файлы

`server/api/`, `web/`

## Критерии приёмки

- Экран соответствует макету по составу и поведению; отличия согласованы с владельцем.
- Ручные элементы сохраняются и помечаются как добавленные вручную до первой проверки.
- Проверка устройства вызывает реальный ping и запрос SNMP, а не заглушку.
- Значки различаются формой, не только цветом; элементы управления доступны с клавиатуры.
- API требует авторизацию, интерфейс слушает только локальный адрес по умолчанию.

## План тестов

Модульные тесты API, тесты интерфейса на фикстуре топологии, ручной проход по сценариям: добавить, назвать, проверить, соединить, разорвать, удалить.

## План отката

`git revert` PR, пользовательские данные карты сохраняются в базе.
