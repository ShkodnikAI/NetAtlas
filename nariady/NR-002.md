# NR-002: Безагентный сканер сети

- **Статус:** draft
- **Риск:** medium
- **Зависимости:** NR-001

## Описание

Сканер первой фазы, запускается с админского компьютера. Источники: ARP/ping по заданным подсетям, DHCP-аренды роутера (если доступны), SNMP на коммутаторах (таблица MAC по портам, LLDP/CDP), список клиентов Wi‑Fi точки, имена через NetBIOS, mDNS и SSDP, производитель по MAC, обёртка над Nmap. Результат: JSON с устройствами и связями, с указанием источника каждого факта.

## Меняемые файлы

`scanner/`, `internal/model/` (типы устройств и связей), тестовые фикстуры

## Критерии приёмки

- Сканируются только подсети из конфигурации; адрес вне списка отклоняется.
- Ограничение скорости и параллельности, значения по умолчанию щадящие.
- Нет глубокого сканирования портов для устройств класса «Гость».
- Топология строится из таблицы MAC по портам и LLDP; неуправляемые коммутаторы показываются как «облако».
- Учётные данные SNMP не попадают в логи и вывод.
- Для каждого найденного устройства указаны источники и время обнаружения.

## План тестов

Модульные тесты на фикстурах ответов SNMP, ARP и DHCP. Интеграционный прогон на изолированной тестовой сети в Hyper-V (виртуальные машины и виртуальный коммутатор), без реальной сети владельца.
