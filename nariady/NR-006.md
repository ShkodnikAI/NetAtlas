# NR-006: Агент Windows: инвентарь и связь

- **Статус:** draft
- **Риск:** high
- **Зависимости:** NR-003, NR-007

## Описание

Агент как служба Windows: регистрация на сервере, исходящее соединение с взаимной проверкой сертификатов, буферизация данных при потере связи. Инвентарь: железо, диски и SMART, драйверы, установленные программы, ОС и обновления. Опрос по расписанию.

## Меняемые файлы

`agent/`, `server/api/agent/`, установщик

## Критерии приёмки

- Агент сам подключается к серверу, входящих портов не открывает.
- Соединение только по mTLS, сертификат агента уникален.
- Агент без выполнения заданий: в этом наряде он только читает данные.
- При недоступности сервера данные копятся локально с ограничением объёма и отправляются позже.
- Агент работает под ограниченной учётной записью службы, насколько позволяет сбор данных.
- Установка и удаление чистые, подписанный установщик.
- Агент показывает значок «ПК под наблюдением».

## План тестов

Модульные тесты сборщиков на фикстурах, установка и удаление на виртуальной машине Hyper-V по снимку-эталону, проверка потери связи и восстановления, затем одна реальная машина по подтверждению владельца.

## План отката

Удаление агента через установщик, `git revert` PR, отзыв сертификата агента на сервере.
