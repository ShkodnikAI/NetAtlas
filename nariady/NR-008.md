# NR-008: Измерения качества сети

- **Статус:** draft
- **Риск:** medium
- **Зависимости:** NR-004, NR-006

## Описание

Измерения агентами: задержка, джиттер и потери до шлюза, сервера и других агентов, скорость интернета, время DNS, bufferbloat. Тяжёлые замеры пропускной способности между парами только в окна простоя. SNMP-счётчики коммутаторов и роутеров. Экран «Качество сети» по макету: матрица связи, график скорости за сутки, список узких мест.

## Меняемые файлы

`agent/measure/`, `server/metrics/`, `web/`

## Критерии приёмки

- Замеры не мешают работе: ограничение объёма трафика, расписание, остановка при высокой загрузке.
- Матрица показывает задержку и потери, состояние «нет данных» для выключенных узлов.
- Узкие места формируются правилами из измерений, без участия ИИ.
- Данные хранятся с политикой уплотнения старых значений.

## План тестов

Модульные тесты расчётов, прогон на тестовой сети с искусственными задержкой и потерями (эмуляция на ВМ), проверка нагрузки замеров.

## План отката

`git revert` PR, отключение измерений флагом в конфигурации.
