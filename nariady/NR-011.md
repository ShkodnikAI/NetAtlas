# NR-011: Конвейер скриптов и Hyper-V тесты

- **Статус:** draft
- **Риск:** high (владеет `pipeline/gate/`)
- **Зависимости:** NR-006, NR-007

## Описание

Репозиторий скриптов со статусами: черновик, проверен, протестирован, подписан, пробный запуск на одном ПК, раскатан. Статическая проверка (PSScriptAnalyzer), пробный режим, тест на Hyper-V по снимку-эталону с откатом снимка, замер «до/после», автоматический откат при отсутствии улучшения. Каталог проверенных действий, произвольный скрипт отдельным правом. Экран «Скрипты и тесты».

## Меняемые файлы

`pipeline/`, `pipeline/gate/`, `server/jobs/`, `agent/exec/`, `web/`

## Критерии приёмки

- Сервер технически не отправляет задание без статуса «протестирован» и подписи владельца; проверка в `pipeline/gate/` и отдельная на агенте.
- Подпись ставится только после явного подтверждения владельца в интерфейсе.
- Для драйверов и сетевых карт этап «Один ПК» обязателен.
- Раскатка группами с остановкой при ошибке.
- Каждое действие записывается в журнал аудита.
- Задания для выключенных машин ставятся в очередь и сохраняют срок действия подписи.

## План тестов

Негативные тесты на обход шлюза (неподписанный, непроверенный, изменённый скрипт), прогон конвейера на ВМ, проверка отката снимка и отката изменения по метрикам.

## План отката

`git revert` PR, остановка очереди заданий, отзыв подписей незавершённых заданий.
