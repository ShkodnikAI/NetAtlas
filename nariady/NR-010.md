# NR-010: Аудит безопасности

- **Статус:** draft
- **Риск:** medium (только чтение, проверки на агентах)
- **Зависимости:** NR-006

## Описание

Проверки изнутри сети: SMBv1, шифрование диска, удалённый рабочий стол без NLA, версия и поддержка ОС, брандмауэр, открытые службы и порты, устаревшее ПО по базе NVD, устройства с заводскими паролями. Оценка по весам, экран «Безопасность».

## Меняемые файлы

`agent/checks/`, `rules/security/`, `web/`

## Критерии приёмки

- Проверки только читают состояние и ничего не меняют.
- Каждое замечание ссылается на основание (рекомендация CIS, жизненный цикл ОС, база NVD) без выдуманных номеров.
- Для подбора паролей и активных атак механизмов нет.
- Оценка воспроизводима, веса документированы.

## План тестов

Тесты на виртуальных машинах с заведомо небезопасными и безопасными настройками, проверка отсутствия изменений состояния.

## План отката

`git revert` PR, проверки отключаются в конфигурации.
