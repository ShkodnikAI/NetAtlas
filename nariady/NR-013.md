# NR-013: Отчёты для ИИ

- **Статус:** draft
- **Риск:** high (граница изоляции ИИ)
- **Зависимости:** NR-009, NR-010

## Описание

Сборщик отчёта по единой форме (что наблюдается, контекст, измерения, ключевые строки логов, уже проверено, вопрос), очистка и псевдонимы, таблица соответствий у владельца, приём ответа ИИ как текста, передача рекомендации в репозиторий скриптов только как черновик. Экран «Отчёт для ИИ». Сначала ручная передача текста, затем подключение API или локальной модели.

## Меняемые файлы

`reports/`, `server/api/reports/`, `web/`

## Критерии приёмки

- Модуль ИИ получает только текст отчёта; у него нет ключей, учётных данных, доступа к агентам, серверу управления и репозиторию скриптов.
- Имена, адреса, пароли, токены, ключи и учётные записи удаляются или заменяются до отправки; тест с контрольными секретами в логах.
- Ответ ИИ отображается как текст и никогда не исполняется; из него создаётся только черновик скрипта.
- Подключение внешней модели включается отдельным подтверждением, с возможностью локальной модели.
- Таблица соответствий псевдонимов не покидает сервер.

## План тестов

Тесты очистки на синтетических логах с секретами и инъекциями вида «игнорируй инструкции», проверка отсутствия сетевых путей из модуля ИИ к остальным компонентам.

## План отката

`git revert` PR, отключение отправки в ИИ флагом.
