# NR-001: Скелет проекта и CI

- **Статус:** draft
- **Риск:** low
- **Зависимости:** нет

## Описание

Создать структуру репозитория для Go-проекта, общий модуль, конфигурацию, линтеры и CI. Без бизнес-логики.

## Меняемые файлы

`go.mod`, `agent/`, `server/`, `scanner/`, `web/`, `rules/`, `reports/`, `pipeline/`, `internal/`, `.github/workflows/ci.yml`, `.gitignore`, `Makefile`

## Критерии приёмки

- Репозиторий собирается одной командой, CI запускает `go vet`, тесты и статический анализ.
- `.gitignore` исключает ключи, сертификаты, `.env`, базы данных и бинарники.
- В репозитории нет секретов; добавлена проверка на секреты в CI.
- Структура соответствует разделу «Состав системы» из README.

## План тестов

Запуск CI на тестовой ветке, намеренный коммит файла с ключом должен блокироваться проверкой.

## План отката

`git revert` PR. Данных и развёртываний нет.
