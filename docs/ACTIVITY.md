# Активность сотрудников (NR-012)

Минимальные сведения о работе за компьютером. **Сбор по умолчанию
выключен** на сервере и на агенте; включение двойное и только после
письменного уведомления сотрудников.

## Что собирается и в каком виде

| Данные | Вид | Источник |
|--------|-----|----------|
| Активное приложение | имя exe (без заголовка окна) | GetForegroundWindow + имя процесса |
| Время в приложении | секунды в 5-минутном окне | агрегат на агенте |
| Домены сайтов | только `host`, без схемы, пути, параметров и заголовков | DNS-кэш клиента (`Get-DnsClientCache`) |
| Активность | секунды за окно | интервалы между снимками |
| Простой | секунды без ввода (порог 60 с) | `GetLastInputInfo` — только время |

Агрегация выполняется **на агенте**: на сервер уходят 5-минутные окна
(приложение → секунды, домен → число запросов в кэше, активное/простой
→ секунды). Сырых событий (каждый клик, каждое переключение окна) не
существует ни на агенте, ни на сервере.

## Что не собирается и в коде отсутствует

- нажатия клавиш и содержимое ввода (нет перехватчиков ввода);
- содержимое писем и переписки;
- пароли;
- полные адреса страниц, заголовки окон, содержимое страниц;
- скриншоты;
- буфер обмена.

Источники, которые нельзя получить без запрещённых данных
(например, история браузера — она лежит в файлах профиля вместе с
заголовками), **не читаются**: вместо них используется DNS-кэш, где
есть только имена доменов. Это зафиксировано в коде и проверяется
тестами (`internal/privcheck`: в коде агентов отсутствуют функции
ввода, снимков экрана и буфера обмена).

## Исключения

- учётные записи членов группы «Администраторы» не собираются;
- учётная запись владельца не собирается (добавьте её имя в
  `exclude_accounts` в `activity.json`);
- компьютеры, для которых сбор не включён на сервере, не собираются —
  сервер отвергает их данные (`403`).

## Как включить (двойное включение)

1. **Сервер**: экран «Активность» → идентификатор агента + точная
   фраза «Сотрудники уведомлены» → «Включить». Без точной фразы
   включение невозможно; факт включения с подтверждением попадает
   в журнал аудита.
2. **Агент на рабочем компьютере**: файл
   `%ProgramData%\NetAtlas\agent\activity.json`:
   ```json
   { "activity_enabled": true }
   ```
   Политика читается на каждый тик: включение/выключение без
   перезапуска службы.

Пока оба флага не включены, данных нет. В коде нет способа включить
сбор неявно.

## Значок «ПК под наблюдением»

Отдельный процесс `netatlas-agent-notify` (ставится вместе с
агентом, автозагрузка пользователя):

```powershell
netatlas-agent-notify install    # автозагрузка + запуск
netatlas-agent-notify uninstall  # убрать
```

Значок показывается всегда, когда сбор включён на этой машине, и
всплывает при первом включении. Когда сбор выключен — значка нет.
Процесс ничего не собирает: только читает локальный файл статуса.

## Хранение и удаление

- данные хранятся **90 дней**; сервер удаляет старше раз в сутки и
  пишет в аудит число удалённых записей (`activity_purge_expired`);
- владелец может удалить собранное по конкретному ПК досрочно:
  экран «Активность» → «Удалить собранное» (`DELETE
  /api/activity?computer=…`, аудит `activity_purge`);
- **каждый просмотр** данных владельцем пишется в аудит
  (`activity_view`).

## Отметка «плохая репутация» домена

Локальная таблица `rules/data/domain_reputation.json` (домен,
категория, источник оценки): применяется на сервере при показе
экрана, никакие домены наружу не отправляются. Таблица по умолчанию
пуста — оценки вносит владелец.

## Текст-шаблон уведомления сотрудников (не юридический совет)

> Уведомляем вас, что на рабочих компьютерах компании с <дата>
> ведётся учёт рабочего времени средствами системы NetAtlas.
> Собираются: активное приложение и время работы в нём, имена
> посещённых доменов (без адресов страниц), время активности и
> простоя. Не собираются и не могут быть собраны технически:
> нажатия клавиш, содержимое переписки и писем, пароли, адреса
> страниц, скриншоты, буфер обмена. Учётные записи администраторов
> не отслеживаются. Данные хранятся 90 дней, доступ к ним имеет
> только администратор системы. О факте наблюдения на компьютере
> свидетельствует значок в области уведомлений. Вопросы и запросы
> на доступ к своим данным: <контакт>.

**Проверьте требования законодательства вашей страны** (уведомление,
согласие, сроки хранения, права сотрудников на доступ к своим
данным) — этот шаблон не является юридическим документом.
